PHASE 4 — TIME & SPACE COMPLEXITY NOTES (C#)
Owner: Afif Hossain

1. TIME COMPLEXITY
Time complexity measures how the number of operations grows with input size n.
We focus on growth rate, not exact time.

2. SPACE COMPLEXITY
Space complexity measures how much EXTRA memory an algorithm uses.
Input itself is not counted. Only additional memory is considered.

--------------------------------
O(1) — CONSTANT
--------------------------------
Time O(1):
int x = 1;
arr[0];

Space O(1):
int sum = 0;

--------------------------------
O(n) — LINEAR
--------------------------------
Time O(n):
for (int i = 0; i < n; i++)
{
    Console.WriteLine(arr[i]);
}

Space O(n):
int[] arr = new int[n];

--------------------------------
O(n^2) — QUADRATIC
--------------------------------
Time O(n^2):
for (int i = 0; i < n; i++)
{
    for (int j = 0; j < n; j++)
    {
        Console.WriteLine(i + j);
    }
}

Space O(1):
No extra memory allocated.

--------------------------------
O(log n) — LOGARITHMIC
--------------------------------
Time O(log n):
int x = n;
while (x > 1)
{
    x /= 2;
}

Space O(1):
Uses fixed variables.

--------------------------------
O(n log n) — LINEARITHMIC
--------------------------------
Time O(n log n):
for (int i = 0; i < n; i++)
{
    int x = n;
    while (x > 1)
    {
        x /= 2;
    }
}

Space O(1):
No extra memory.

--------------------------------
O(2^n) — EXPONENTIAL
--------------------------------
Time O(2^n):
int Fib(int n)
{
    if (n <= 1) return n;
    return Fib(n - 1) + Fib(n - 2);
}

Space O(n):
Recursive call stack.

--------------------------------
KEY RULES
--------------------------------
• Loops affect TIME, not SPACE
• New arrays/lists affect SPACE
• Space complexity = maximum memory at any moment

ORDER OF GROWTH:
O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n)
